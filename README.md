# 🍔 Python Food Order System

## 📌 Description

This is a command-line food ordering system built in Python.

Users can view the menu, select food items, add them to the cart, and get the final bill.

## 🚀 Features

* Displays food menu with prices
* Uses dictionary for menu data
* Validates user input
* Adds selected items to cart
* Calculates total bill automatically
* Exit anytime using `q`

## 🛠️ Concepts Used

* Python Dictionaries
* Lists
* Loops
* Input Validation
* `.items()`
* `.get()`

## ▶️ How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/your-username/python-food-order-system.git
   ```

2. Open the project folder

3. Run the file:

   ```bash
   python food_order_system.py
   ```
